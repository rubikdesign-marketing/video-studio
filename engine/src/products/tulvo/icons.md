# Tulvo UI icons (identified from the live DOM)

GENERATED by `node src/tulvo/ui/tools/identify-icons.mjs` from `research/ui-live/dom/*.html`. Do not edit by hand.

How: every `<svg>` in the 14 snapshots was compared, shape by shape (tag + geometry attributes, ignoring stroke/fill
styling), with every icon in the installed **lucide-react@0.479.0** (pinned exact in package.json). That version
was chosen because it reproduces the app's icons exactly: versions 0.469–0.479 match every lucide-classed SVG
geometry, and only versions before 0.487 emit the app's single class form (`lucide-trash2`, not `lucide-trash-2`).

Use: `import { Plus } from "lucide-react"` and pass the DOM's extra classes, e.g. `<Plus className="h-4 w-4 text-muted-foreground" />`.
lucide-react adds `lucide lucide-<name>` itself. Copy non-default `stroke-width` (e.g. Deploy/Data Templates use 1.5) and
`width/height` attributes (e.g. the workspace chevron is `size={16}`).
