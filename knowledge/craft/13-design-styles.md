# Design styles

Six style families, each built only from the brand's own colours and fonts (`brands/<brand>/brand.json`), by role. A video picks one at the moodboard, or blends two with a stated reason. Logo, typeface and caption style are the same in all of them.

Each video must look different from the last five in the ledger. Changing family is the simplest way; changing the stage treatment, signature move and accent use inside a family is the other.

## 1. Paper

Calm and clear. The product is the whole show.

| | |
|---|---|
| Page | The brand's light page, fine grain |
| Ink and accent | Ink; the accent for the one highlight |
| Type | The headline face; two-part headlines in ink then muted grey; small labels in sentence case |
| Product | White windows with a line border and a long soft shadow |
| Light | One soft light from the upper left; no glow |
| Motion preset | calm or confident |
| Signature devices | A large cursor as guide, continuous camera, hidden cuts, rests for reading |
| Sound | Soft keys or light percussion, 80–105 beats a minute, dry interface sounds |
| Suits | Demos, tutorials, calm launches |

## 2. Night

Celebratory and bright against dark. Proven on Tulvo's Black Friday film.

| | |
|---|---|
| Page | The brand's dark page with slow pools of its accent, grain |
| Ink and accent | Ink on dark; the second colour for the second clause; the accent; the warm note for old prices and deadlines |
| Type | The headline face, large; the accent face for one word |
| Product | Light UI lit as a screen in the dark, with a faint glow at its edges |
| Light | Light comes from the product; a horizon of light for endings |
| Motion preset | hype or confident |
| Signature devices | The offer ticket, a rolling price, confetti at the announcement |
| Sound | 120–128 beats a minute, a lift before the offer, an impact on it |
| Suits | Sales, big announcements |

## 3. Glass

Layered and precise. Good for AI features and anything about connection.

| | |
|---|---|
| Page | The brand's soft fill fading to its light page, or its dark page for a dark version |
| Ink and accent | Ink; the accent |
| Type | The headline face; small labels on the glass panels |
| Product | UI panels float at different depths behind and in front of frosted glass |
| Light | Light passes through panels; edges catch a thin highlight; one light sweep on the key reveal |
| Motion preset | confident |
| Signature devices | Focus pulls between layers, depth, the layered camera |
| Sound | Airy pads, glassy interface sounds, 95–115 beats a minute |
| Suits | Feature launches, AI and integrations |

## 4. Colour field

Bold and simple. One saturated colour edge to edge.

| | |
|---|---|
| Page | The accent colour full frame; the light or dark page as the contrasting beat |
| Ink and accent | Type in the page colour; ink for buttons; the warm note once |
| Type | The headline face at its largest; very few words |
| Product | White windows sitting on the colour, cropped tight |
| Light | Flat, graphic; shadows short and crisp |
| Motion preset | hype |
| Signature devices | Shapes that become objects, hard cuts on the beat, type that fills the frame |
| Sound | Punchy, rhythmic, 115–128 beats a minute |
| Suits | Hooks, short ads, offers, cut-downs |

## 5. Editorial

Confident and human. Reads like a well-designed magazine.

| | |
|---|---|
| Page | White with generous margins; one full-bleed image or screen per beat |
| Ink and accent | Ink; the accent used sparingly as underline or mark |
| Type | The headline face with the accent face doing real work in headlines; small sans labels for captions and dates |
| Product | Screens presented like photographs, with a caption line under them |
| Light | Natural, soft |
| Motion preset | calm |
| Signature devices | Type-led openings, slow pushes on stills, drawn underlines, numbered chapters |
| Sound | Warm, acoustic or minimal piano, 75–95 beats a minute |
| Suits | Customer stories, edits of filmed footage, thought-leadership pieces |

## 6. Blueprint

Technical and exact. Shows how things connect.

| | |
|---|---|
| Page | The brand's light page or dark page, with thin construction lines in the line colour (solid lines only) |
| Ink and accent | Ink; the accent for the active path |
| Type | Small precise labels lead; the headline face for the few headlines |
| Product | UI pieces as components on a diagram, joined by lines that draw themselves |
| Light | Flat |
| Motion preset | confident |
| Signature devices | Line draws, nodes lighting in sequence, data travelling along a path, zoom out to the system |
| Sound | Precise clicks and ticks, a low steady pulse, 100–115 beats a minute |
| Suits | Automation, webhooks, integrations, "how it works" |

## Choosing a style

| Video | First choice | Alternative |
|---|---|---|
| Sale or offer promo | Night | Colour field |
| Feature launch | Glass | Paper |
| Feature demo | Paper | Glass |
| Tutorial | Paper | Blueprint for technical topics |
| Automation or integration | Blueprint | Glass |
| Customer story or edit of footage | Editorial | Paper |
| Six-to-fifteen-second ad | Colour field | Night |

## Blending

Two families may meet in one film at the turn of the story (for example Paper for the product, then Night for the offer). The change happens once, at a planned moment, through a push-through or a shape that becomes the next page colour. Never alternate.

## Adding a family

A new family is proposed at a moodboard, approved there, used in a video, then written into this file with its tokens. It must be built only from brand colours and fonts.

## What stays out of every family

Anything the brand rejects, dots of any kind (grids, separators, pill dots), coding-style typefaces, mesh blobs, glitch and RGB-split effects, stock textures, and anything recognisable as another brand's look.
