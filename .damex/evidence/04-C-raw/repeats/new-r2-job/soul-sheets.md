# Idea: three concepts for "Saved replies" (30 s, 16:9, voice-over)

Common to all: promo, 16:9, cap 30 s (binding), confident energy, voice Justin. The ledger for the demo brand is empty, so nothing is repeated from earlier videos. Facts that must be right: saved replies let you write an answer once, save it, pick it from a list, change a line and send. Nothing more is claimed.

## A. The fifth time (RECOMMENDED, treated as approved)

| | |
|---|---|
| Hook family | Before and after (demonstration) |
| Design style | Calm and clean on the off-white page; green accent only on what you act on |
| Length / energy | 30 s, confident; the peak is one small beat, not a flourish |
| Flow pattern | Problem, one action, the same action again, result |

- **One sentence:** "Their support inbox stopped making me type the same answer over and over."
- **Feeling:** Relief, then pride that the reply still sounds like you.
- **One idea:** The same question arrives five times. The fifth is the moment you stop typing. The five identical messages are answered from one saved reply.
- **Signature moment (about 3 s, scene 4):** The saved reply is edited by a single line for one customer, and "Still sounds like you" lands as the word you changed gets the green accent.
- **Stage:** The off-white page with the support inbox as the only thing in frame.
- **Never:** a made-up statistic or time saved; a screen that is not clearly a stand-in or a real capture; a robotic, canned tone.
- **Different from the last five:** nothing earlier to compare with.
- **New to the library:** the stack-to-one move (five repeated items collapse into one saved item).
- **Why recommended:** it states the viewer's pain in the first second, proves the feature in two plain actions, and keeps the worry that canned replies sound canned inside the film and answers it. It is the only one that makes a claim we can fully stand behind.

## B. The queue clears

| | |
|---|---|
| Hook family | Audience callout |
| Design style | Dark green night page, bright accent |
| Length / energy | 30 s, hype |

- **One sentence:** "A long queue got short."
- **One idea:** An inbox of tickets that disappears row by row as replies go out.
- **Signature moment:** The queue count falling to zero.
- **Risk:** The count implies a speed result we have no evidence for, and "queue cleared" is a claim about outcomes, not the feature. It also needs invented data.
- **Not recommended.**

## C. Say it once

| | |
|---|---|
| Hook family | Contrarian |
| Design style | Type-led, almost no UI until scene 3 |
| Length / energy | 30 s, calm |

- **One sentence:** "Stop writing the same sentence."
- **One idea:** One sentence in large type repeats until it is replaced by a single saved item.
- **Signature moment:** The repeated sentence collapsing into one line.
- **Risk:** It is a type film, so the product barely shows for a feature announcement, and the viewer is left asking how it works.
- **Not recommended.**
