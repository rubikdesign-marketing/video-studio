# Product

Demo brand is a test brand. Its product is made up: a small customer dashboard for an invented "Acme workspace",
in `library/fixtures/demo-product/`, served on this Mac only:

```
node library/fixtures/demo-product/serve.mjs        # http://127.0.0.1:4317
```

It is filmed only for the style library's capture-family previews (`jobs/_demo-previews`), so no client's product
ever appears in them. Every company name in it is invented and starts with Acme or Demo; it shows no people and no
e-mail addresses. `capture.json` says how the capture tool films it.
