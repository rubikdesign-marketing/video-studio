# Pronunciation

How to write words in voice scripts so they are said correctly. Captions and on-screen text always use the real spelling.

| Word | Write it as | Said |
|---|---|---|

Add a row whenever a voice take mispronounces a product word. For example, a product called "Tulvo" is written "Toolvo" in the script so the voice says TOOL-voh, and the captions still show "Tulvo".
